# Printout Style Guide & Thermal Specifications

This document defines the technical and visual standards for receipt slips generated by the Active Sefton Slip Printer application.

---

## 1. Principles of Thermal Printing

Thermal receipt printers (e.g. Epson TM-T88 series, Star TSP100 series) use heat-activated paper rather than ink. This introduces specific constraints:

1. **Monochrome Only (No Greyscale):** Thermal heads can only heat or not heat. Greyscale, light greys, and pale borders trigger printer dithering (halftone patterns) which reduces legibility. All slip text, lines, and borders must be pure `#000000` black.
2. **Fixed Roll Width (80mm Standard):** The printable area across an 80mm roll is roughly 72mm (~200 to 250 pixels at print resolution). Layouts are constrained to `width: 250px` to guarantee nothing clips off the edge.
3. **Zero Browser Headers & Footers:** Thermal slips must not include URL headers, date stamps, or page numbers injected by browsers. The application forces `@page { margin: 0; }` and zero body padding.
4. **Dynamic Cut Lines:** When printing batches (10x copies), each slip is separated by a 1px dashed black border acting as a visual scissor line or tear guide.
5. **Receipt Identification:** Every slip concludes with a tiny `-MDW-` centering tag (`font-size: 4px`, centered) to identify the Meadow Leisure Centre origin.

---

## 2. Global Styling Standards

* **Font Family:** Sans-serif (System default: Arial, -apple-system, Roboto, BlinkMacSystemFont). Web fonts are avoid in the print stream to prevent font loading delays or print fallback issues.
* **Text Color:** Black (`#000000`) strictly enforced.
* **Text Alignment:** Center by default. Two-column rows use flexbox with space-between.
* **Paragraph Spacing:** Reset default margins (`margin: 0; padding: 0;`).
* **Print Margins:** 0px.
* **Internal Padding:** `15px 5px` for slip container; `padding: 0 4px` for internal flexbox rows.

## 3. Typography Hierarchy

### Type A: Standard Contact Slips (Retention, Aquatics, Meadows Contact)
* **Title:**
  * Font Size: `24px`
  * Font Weight: `700` (Bold)
  * Margin Bottom: `4px`
* **Phone & Email:**
  * Phone Number: `20px`, Weight `400`
  * Email / Subtext: `14px`, `white-space: nowrap`
  * Margin Bottom: `4px`

### Type B: Access Code Slips (Changing Rooms, Sauna & Steam)
* **Title:**
  * Font Size: `24px`, Weight `700`
  * Margin Bottom: `8px`
* **Code Display:**
  * Font Size: `32px`
  * Font Weight: `700` (Bold)

### Type C: Timetable Slips (Gym Times, Swims, Rhymetime)
* **Title:**
  * Font Size: `20px` - `24px`, Weight `700`
  * Margin Bottom: `4px` - `10px`
* **Section Dividers:**
  * `1px dashed #000` top and bottom borders
  * Font Size: `14px`, Weight `600`, Margin: `8px 0`
* **Two-Column Activity Rows:**
  * Container: `display: flex; justify-content: space-between; width: 100%; padding: 0 5px; font-size: 15px-16px;`
  * Left Column (Day / Category): Weight `600` (Semi-bold), `text-align: left`
  * Right Column (Times): Weight `400` (Regular), `text-align: right`

### Type D: Vertical Warning / Out of Order Notices
* Used for taping to doors, cubicles, or coolers.
* **Orientation:** `writing-mode: vertical-rl; text-orientation: mixed;`
* **Main Notice:**
  * Font Size: `48px` - `64px`, Weight `800` / `900`
  * Uppercase keyword emphasis (e.g. `NOT`, `BROKEN`, `OUT OF ORDER`)
* **Timestamp / Subtext:**
  * Font Size: `20px` - `38px`, Weight `600` - `700`
  * Dynamic UK date-time: `MANAGER NOTIFIED: DD/MM/YYYY HH:MM`

### Type E: Pricing Slips
* **Title:** `24px`, Weight `900`
* **Category Blocks:** Separated by `1px dashed #000` borders with `padding-bottom: 8px`.
* **Category Titles:** `16px`, Weight `700`, `text-align: left`.
* **Rates:** Committed & Non-Committed rates aligned left & right at `13px`.
* **Standard Age Groups:**
  * Adult
  * Youth (11-15yrs)
  * Swim (Junior 3-10)

## 4. Dual Output Pipelines

### 1. Thermal Window Stream (`handlePrint()`)
* Creates an isolated popup window (`width=800,height=600`).
* Writes an HTML document with minimal inline `@page` reset and thermal slip container styling.
* Sets a 500ms timeout for rendering assets (such as QR codes) before invoking `window.print()` and immediately closing the window.

### 2. A4 Sheet Export (`handleExportPng()`)
* Uses `html2canvas` to capture the `#paper` element at `scale: 4` (high resolution).
* Creates an off-screen HTML5 `<canvas>` sized to A4 landscape at 300 DPI (`3508 × 2480 px`).
* Stamps 4 identical slip passes side-by-side with dashed scissor guides.
* Automatically downloads as `slip-export-a4.png`.
